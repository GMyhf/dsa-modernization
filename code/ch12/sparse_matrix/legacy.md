# 稀疏矩阵证据

原书 12.1 的十字链表只有结构说明，本单元补充可测试实现。
每个非零结点同时出现在行链和列链；行链拥有结点，列链只保存观察指针。
更新零值会删除结点，更新非零值会复用结点，列链随后重建以保持顺序。

```text
$ python3 tools/check_code.py code/ch12/sparse_matrix --allow-degraded
SparseMatrix: 3 checks, 0 failures
```

实现不使用 STL 容器代替链表，不执行 I/O；Sanitizer 受当前 macOS 环境限制。
行链按列下标递增，列链按行下标递增；测试同时检查随机访问和列遍历。
设置已有非零元只更新值，设置为零才删除结点，避免把零保存为伪非零元。
越界行列会抛出 `std::out_of_range`，空矩阵也能安全构造和销毁。
列链接不拥有结点，析构只沿行链释放，避免双重释放。
本单元不宣称实现 CSR，CSR 仍由第 12 章习题作为另一种压缩表示练习。
实现的所有权方向是单向的：行链使用 `unique_ptr`，列链只观察行链结点。
因此更新列链接不会改变结点的析构责任。
测试使用 4×5 矩阵，覆盖非零元插入、读取、列扫描和删除。
矩阵维度以 `size_t` 保存，非法下标在进入链操作前被拒绝。
空值不创建结点，保持 `nonzeros()` 与实际存储一致。
这组断言是 Release-O2 运行结果，不把未运行的 sanitizer 写成已验证。
