# 原书写法 → 问题 → 现代写法：树状数组

本单元是课件新增内容，原书 105 条清单没有树状数组条目，因此不伪造原书缺陷编号。

## 教学目标

树状数组把固定数组的动态前缀和拆成若干个由 `lowbit(i)` 决定的连续块。公共接口使用 0 起始下标；内部数组保留一个空的 0 号位置，使 `i += lowbit(i)` 能沿更新路径上行，`i -= lowbit(i)` 能沿查询路径回退。

## 现代实现的取舍

- `add` 是单点增量，`set` 通过当前值计算增量，避免把两种语义混在一起。
- `prefix_sum(end)` 和 `range_sum(left,right)` 使用半开区间，空区间自然为 0。
- 所有边界错误抛 `out_of_range`/`IndexError`，不打印提示。
- `vector`/Python `list` 是本算法要讲的连续存储载体，不是用容器替代另一章的结构。

## 可复现证据

测试用暴力前缀和逐个对拍 0..8 个元素的全部半开区间，覆盖负数、零、空区间、单点更新、赋值更新和越界。

`cases.tsv` 由 C++ 与 Python 共读，修改任意期望值后两侧应同时失败；这条由 T-047 闸门执行。

测试还刻意使用负数和零，避免把“所有值都为正”的样例误当成前缀和不变量。`set` 的测试先写入一个值再改写它，验证内部树和原数组快照同步。空区间、全区间和单元素区间分别走了不同的循环边界。

变异探针把 `cursor -= lowbit(cursor)` 改成 `cursor += lowbit(cursor)` 时会在查询中越过边界并失败；把半开区间的 `prefix_sum(left)` 删除时，所有非零左端点的区间对拍都会失败。这两条是算法行为证据，不依赖输出格式。

## 验证边界

实现只支持可加的 `long long` 数值，不提供区间更新、二维树状数组或坐标离散化。`lowbit(0)` 没有业务意义，内部循环不会把 0 当作更新下标。
