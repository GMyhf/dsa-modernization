# 存储回收证据

原书 12.2.3--12.2.4 只有分配策略、引用计数和标记清除的概念说明。
本单元用手写对象链模拟堆：根出发递归标记可达对象，再扫描并删除未标记对象。
无根环会被整体回收，这是引用计数无法做到的边界。

```text
$ python3 tools/check_code.py code/ch12/storage_recovery --allow-degraded
StorageRecovery: 3 checks, 0 failures
```

实现仅用于教学，不替代运行时或操作系统的真实垃圾回收器。
测试包含一条可达链和一个无根环，分别验证保留与整体回收。
标记位在每轮清扫后复位，因此同一堆可以重复执行收集。
对象链是教学用的手写元数据，不把 `std::shared_ptr` 当成标记清除实现。
根集合在本示例中由调用者显式传入，真实程序还需扫描栈和全局根。
回收复杂度为可达图遍历加全堆扫描，分别是 `O(E+V)` 与 `O(H)`。
循环引用不会因引用计数下降而释放，这正是标记清除的动机。
对象的 `edge` 字段代表图中的一条引用边，`next` 字段只属于模拟堆的对象目录。
清扫阶段先摘链再删除，避免访问已经释放的后继指针。
根对象仍然由调用方持有，收集器不会猜测栈上的任意整数是否为指针。
测试先保留可达链，再验证无根环被清除，覆盖两种最重要的可达性结果。
本单元没有并发、压缩或分代回收承诺，教学目标是标记与清扫的基本不变量。
Sanitizer 在当前 macOS 环境的空探针失败，以上结果为 Release-O2 验证。
