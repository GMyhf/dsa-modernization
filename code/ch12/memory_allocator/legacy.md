# 12.2.3 存储的动态分配和回收

## 原书给了什么

原书 12.2.3 只有文字：首次适应、最佳适应、最坏适应三种挑块策略，相邻空闲块应当合并，
以及**边界标记**（块头块尾各记一份大小与忙闲）让合并可以在常数时间完成。
**没有 `【算法】`/`【代码】` 清单**，本单元是新增实现。

## 第一版的三个问题，都是实测出来的

第一版（`f435ec6`）用定长 `Block[]` 池加手工维护的前后指针索引。

**1. 分裂的守卫拿块数去比字节数，会写越界。**

```cpp
if (b.size > bytes && count_ < capacity_)   // capacity_ 是竞技场的字节数，不是 max_blocks
```

构造函数把 `capacity_` 设成竞技场大小（字节），`max_blocks` 只用来开数组。于是
`BoundaryAllocator(1000, 8)` 只有 8 个块槽位，守卫却允许 `count_` 涨到 1000：

```text
$ g++ -std=c++17 -O1 -g -fsanitize=address,undefined ... probe.cpp
$ ./probe
ERROR: AddressSanitizer: heap-buffer-overflow
```

**2. 合并从不归还元数据槽位，普通的分配/释放循环就会越界。**
`merge()` 把相邻块并进来之后，被并掉的那个槽位再也没人回收，`count_` 只增不减。
用默认的 `max_blocks=128` 跑一个最朴素的循环——每轮分配 10 字节再立刻释放——
同样 `heap-buffer-overflow`。这不是边界情形，是最常见的用法。

**3. 三种策略从头到尾没被区分开。** 第一版的测试对 First / Best / Worst 循环断言
**完全相同**的行为，因为它只在一块空闲区上测——那种布局下三者必然挑中同一块。
把最佳适应和最坏适应的判据对调：

```text
BoundaryAllocator: 15 checks, 0 failures     ← 全绿
```

这个单元的正题就是三种策略的差别，而测试分辨不出来。

## 现在这一版

- **块表按偏移升序、覆盖整段空间、无空洞**，「相邻块」就是表里相邻的项，
  释放时左右各看一眼即可合并。没有手工维护的前后指针，也就不会有「忘了归还槽位」。
- 原书的**边界标记**解决的是同一件事：让一个块在 $O(1)$ 内找到物理相邻的邻居。
  这里用有序块表表达同一个想法，代价是定位要扫表、插入删除要挪动表项——
  如实写在类注释里，不冒充 $O(1)$。
- **合并先合右再合左**：先处理右边，左边的下标才不会失效。

## 可复现的证据

```text
$ cd code/ch12/memory_allocator
$ g++ -std=c++17 -Wall -Wextra -Wpedantic -Werror -O1 -g \
      -fsanitize=address,undefined -fno-sanitize-recover=all test.cpp -o /tmp/ma
$ /tmp/ma
BoundaryAllocator: 37 项断言，0 失败
```

**变异自检**（三处，都见红——第一条正是第一版看不见的那个）：

| 把实现改成哪种错法 | 后果 |
| --- | --- |
| 最佳与最坏适应的判据对调 | 4 条红 |
| 合并时只看右边、不看左边 | 4 条红 |
| 大小相等时也分裂（产生 0 字节的块） | 4 条红 |

## 验证边界

- 37 项断言，`-Werror` + ASan/UBSan 与 `-O2` 双档通过。
- **区分三种策略的用例是核心**：四个大小不同的空洞（500 / 200 / 300 / 600），
  中间用已分配块隔开使其不合并，同一个请求 212 字节——
  首次适应挑 500 那块、最佳适应挑 300、最坏适应挑 600，剩下的碎片分别是 288 / 88 / 388。
  这三个数正好演示了各自的代价。
- 外部碎片有直接断言：释放出两个不相邻的 30 字节空洞后，空闲总量 60、最大块只有 30，
  45 字节的请求失败；合并之后同样的请求就能满足。
- 5000 轮分配/释放，每轮都要求合并回一整块且块表只有一项——第一版在这里越界。
- **不在范围内**：没有对齐、没有多线程、没有真实的 `sbrk`/`mmap`；
  块内不存边界标记（这里靠有序表定位邻居）；没有实现伙伴系统或分离空闲链表；
  `release()` 按偏移线性查找，是 $O(块数)$。
