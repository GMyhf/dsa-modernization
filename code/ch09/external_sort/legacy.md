# 第9章外部排序

## 原书逐条核对

- 【算法9.1】置换选择以最小堆选择当前最小关键码，把不属于当前顺串的输入冻结到下一轮。
- 【代码9.2】赢者树支持初始化、取得最终赢家和从变化选手到根的重赛。
- 【代码9.3】败者树把每轮失败者留在内部结点，变化选手沿路径重赛，面向多路归并。
- 现代 `replacement_selection` 保留堆选择过程，返回完整有序输出而非写磁盘；真正的分段缓冲和
  文件 I/O 属于外存适配层，不应伪装成算法容器的全局状态。
- `TournamentTree` 使用完全二叉数组保存赢家索引；`replace` 只重算从叶到根的路径。
- `winner()` 对空树返回 `optional`，没有使用书中哨兵最大值与未声明的全局缓冲区。

## OCR 与编译证据

【代码9.2】原稿的类声明存在 `int * tree;`、`int * player;` 的裸数组所有权，析构、复制和
赋值的规则未给出。OCR 中还有 `if (n < 2) return;` 后缺失分支边界，不能逐字作为实现。

原稿【代码9.3】把成员声明识别成 `int lowExt, offset;` 与间隔化的 `B[ p/2]`；最小 OCR 片段
中的孤立 `1` 无法编译：

```text
$ printf 'int main(){ int value = 0; 1 }\n' | g++ -std=c++17 -x c++ -
<stdin>:1:30: error: expected ';' before '}' token
```

## 验证边界

测试覆盖空/单元素、负数、重复关键码、稳定的同值赢家选择、两次重赛和非法选手。实现没有调用
`std::sort`、`std::make_heap` 或 `std::sort_heap`。本实现不模拟磁盘块耗尽、冻结标记和多路文件
归并；这些外部 I/O 策略须在拥有文件句柄的上层另行实现。
