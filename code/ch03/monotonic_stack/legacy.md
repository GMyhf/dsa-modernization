# 课件新增算法：单调栈

原书没有单调栈清单，本单元不认领 105 条台账；它承接课件新增的算法内容。

## 核心不变量

栈里保存的是还没有找到答案的位置，而不是值本身。扫描到新位置 `i` 时，若当前值已经严格大于栈顶位置的值，就可以确定栈顶位置的下一个更大值是 `i`，随后弹出它。新位置入栈后，栈顶候选仍按值单调排列。

把“大于”换成“小于”就得到下一个更小值。相等值不弹出，因此答案是“严格”更大/更小；这也是重复值测试必须存在的原因。

## 直方图

直方图算法在末尾虚拟压入高度 0，统一清理所有尚未结算的柱子。柱子弹出时，新的栈顶是它左侧第一个更矮的位置，当前位置是右侧第一个更矮的位置，二者之间的宽度就是这根柱子能覆盖的最大宽度。

## 现代实现与证据

- C++ 和 Python 都手写索引栈，不调用 `std::stack` 或第三方库。
- 下一个更大/更小值用二次暴力算法独立对拍；直方图用枚举每个区间的最小高度对拍。
- 每个位置最多入栈一次、出栈一次，所以时间复杂度为 `O(n)`，栈与答案为 `O(n)`。
- 负高度拒绝，空直方图返回 0，严格比较和重复值分别有测试。

`cases.tsv` 由两种语言共读；改坏一条期望值时，T-047 共享表变异会让两侧都失败。

测试的暴力参照不使用单调栈：下一个更大/更小值逐个向右扫描，直方图逐个枚举区间并维护最小高度。这样即使实现把答案数组初始化成固定样例，随机形状和重复值仍会把它击穿。

把严格比较改成非严格比较会改变重复值的候选边界；把末尾虚拟 0 删除会留下未结算的递增柱子。测试中的等值序列、递增直方图和空输入分别覆盖这些边界。

异常路径也不是装饰：负直方图高度必须在进入栈循环前拒绝，否则面积会出现负值并掩盖调用方错误。
