## 为什么单独存一份

两份题库都声称「按大纲逐条配题」，期末那份开头还有一张**大纲对照表**
（大纲条目 → 题号）。这个说法要能被核对，**大纲本身就必须在仓库里**——
否则对照表指向的是一份只存在于某次对话里的文档，谁也没法复查。
这与 `dsa_raw.md` 的地位相同：它是**证据**，不是可以随手改写的正文。

## 规矩

1. **逐字保留**。措辞、编号、★ 标记一律照原件；原件里的 markdown 瑕疵
   （不成对的 `**`、缺字的条目）也不修——修了就不再是原件。
   需要澄清的话写在文件开头的引用块里，不动正文。
2. **换了大纲要新开一个文件**，按学期命名，不要覆盖旧的。
   历年大纲摆在一起，才看得出哪一条变过。
3. **换大纲后必须重新核对照表**。闸门检查不了「题库对不对得上大纲」——
   这一条属于 `collab/UNVERIFIED-RISKS.md` 第四节那类「闸门管不到的地方」。
