## 3

### 算法过程

算法步骤
- 生成子集和：利用二进制枚举法生成所有子集。
- 排序结果：将所有子集和放入列表中，排序输出。

```cpp
// 计算子集和的函数
vector<int> subsetSums(const vector<int>& A) {
    int n = A.size();
    vector<int> subsetSums;

    for (int mask = 0; mask < (1 << n); ++mask) {
        int currentSum = 0;
        for (int i = 0; i < n; ++i) {
            if (mask & (1 << i)) { 
                currentSum += A[i];
            }
        }

        subsetSums.push_back(currentSum); 
    }

    // 排序
    sort(subsetSums.begin(), subsetSums.end());

    return subsetSums;
}
```

### 时间复杂度

排序和求和时间复杂度都是$O(n \cdot 2^n)$所以总时间复杂度是$O(n \cdot 2^n)$
