# 课件文本

上一级目录里那 19 份 `.ppt` / `.pptx` 抽出来的纯文本，**入库是为了能 grep、能 diff、
能在交接记录里按行引用**。二进制课件这三件事都做不到。

> **原始课件才是依据。** 本目录只有文字与演讲者备注：图片、公式排版、动画、
> 母版上的内容一概丢失。对照时若发现文字讲不通，回去看原文件。

## 怎么来的

```bash
# 1. .ppt 是 2003 及以前的二进制格式，先转成 .pptx（LibreOffice 是外部程序，不是本仓库的依赖）
libreoffice --headless --convert-to pptx --outdir /tmp/slides "ref_数据结构与算法A 2021秋"/*.ppt

# 2. 原本就是 .pptx 的直接拷过去
cp "ref_数据结构与算法A 2021秋"/*.pptx /tmp/slides/

# 3. 抽文本。纯标准库，见红线第 8 条
python3 tools/extract_slides.py /tmp/slides -o "ref_数据结构与算法A 2021秋/课件文本"
```

中间产物 `/tmp/slides/*.pptx` **不入库**——它们由第 1 步随时可再生，
入库只会让同一份内容有两个可能漂开的副本。

## 里面有什么

| | 份数 | 页数 | 带备注的页 |
| --- | --- | --- | --- |
| 12 章正课 | 12 | 1194 | 89 |
| 作业习题课（1\~3 / 4\~6 / 7\~9 / 10\~12） | 4 | 115 | 18 |
| 补充课（动态规划初步、递归转非递归） | 2 | 70 | 1 |
| 第 12 章补充（数据摘要结构） | 1 | 32 | 14 |
| **合计** | **19** | **1411** | **122** |

**演讲者备注是这批文件里最值钱的部分**——它是讲课时说的话，正式教材里没有。
抽取时会丢掉「幻灯片编号」占位符（`<number>` 之类），那不是讲稿内容。

文本里的分页标记是 `===== 幻灯片 N =====`，备注跟在 `--- 演讲者备注 ---` 之后，
所以「第几页讲了什么」可以直接定位。
