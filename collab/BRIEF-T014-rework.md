### 3. 第 8 章确有 D-001 §2 违规

```cpp
inline void quick(std::vector<int>& a) { std::sort(a.begin(), a.end()); }
inline void heap(std::vector<int>& a)  { std::make_heap(...); std::sort_heap(...); }
inline void radix(std::vector<int>& a) { counting(a); }
inline void cycle_index(std::vector<int>& a) { quick(a); }
```

第 8 章的正题就是这些排序算法本身。`d001_exceptions` 里的理由
「使用标准库 heap 与 merge 作为已验证的算法基础设施」**恰恰承认了替代事实**。
逃生口机制没坏（它只要求理由非空），不成立的是理由——而理由正当与否
只能由复核方判断，我判断它不成立。

快排、堆排、基数排序必须手写。`std::sort` 可以留在测试里当**参照物**
（像第 4 章用 `std::string::find` 对拍那样），但不能是实现。
