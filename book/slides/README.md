# 课件

`book/slides/*.md` 是课件的**唯一事实源**，`book/slides/site/` 是渲染产物。

```bash
python3 tools/build_slides.py          # 渲染到 book/slides/site/
python3 tools/build_slides.py --check  # 只校验产物是否最新（闸门用）
```

放映：浏览器打开 `book/slides/site/index.html`（双击即可，不需要起服务）。
线上：<https://gmyhf.github.io/dsa-modernization/slides/>——教室的机器打开链接就能讲。
导出 PDF：在浏览器里打印（Ctrl/Cmd+P），每页一张幻灯片。

## 为什么不是 .pptx

课件要改、要 review、要跟着书稿一起演进。二进制文件在 git 里只能看到
「已变更」三个字——2026-08-16 之所以把 19 份旧课件抽成文本入库，就是因为这个。
Markdown 还有一个 .pptx 给不了的好处：**幻灯片上的代码由闸门逐字核对**。

## 写法

```text
---
title: 第3章 栈与队列
subtitle: 现代 C++ 数据结构教程
---

# 这一页的标题

- 要点一
- 要点二

<!-- 备注
讲课时说的话。放映时按 N 才显示，投影上看不见。
-->

---

# 下一页
```

- **分页**：单独一行 `---`。代码围栏里的 `---` 不会被当成分页符。
- **标题**：每页第一个 `#` 就是这页的名字，会出现在缩略图总览里。
- **备注**：`<!-- 备注 ... -->`。用 HTML 注释是为了在任何 Markdown
  阅读器里都隐身，源文件直接读不会被讲稿打断。
- **插图**：写成 `!` + `[图注]` + `(../assets/xxx.jpg)`。路径按**源文件所在目录**算，
  所以比书稿多一级 `../`（R4 就是这么查文件在不在的）。

## 代码：只准引用，不准手抄

```text
```cpp file=code/ch03/array_stack/teaching.hpp#fn:push
```
```

两种切法：

| 写法 | 取什么 | 什么时候用 |
| --- | --- | --- |
| `#锚点` | 源码里 `// >>> 锚点` 到 `// <<< 锚点` 之间 | 源码本来就有锚点（`modern.hpp` 大多有） |
| `#fn:名字` | 名为「名字」的函数定义，连同紧贴其上的注释 | **教学版**（`teaching.hpp` 故意不留锚点） |

`#fn:` 是为课件加的：`teaching.hpp` 在书稿里是**整块印出来**的，
往里塞十几对锚点注释等于把 D-012 刚清掉的噪声又请回来。按名字找则源码不用动。

同名重载会**一并取出**（中间空一行）。这对讲课往往正好——比如
`#fn:enqueue` 同时给出顺序队列和链式队列两个版本，正好并排对照。

写完跑 `python3 tools/sync_book.py --write` 把代码灌进去，
`check_doc.py` 的 R3 会逐字核对。**屏幕上投的代码 = 学生 clone 下来能跑的代码。**

## 放映快捷键

| 键 | 作用 |
| --- | --- |
| `→` / 空格 / `PageDown` | 下一页 |
| `←` / `PageUp` | 上一页 |
| `Home` / `End` | 首页 / 末页 |
| `N` | 演讲者备注（投影上看不见，自己看） |
| `O` | 缩略图总览，点击跳转 |
| `F` | 全屏 |
| `D` | 深色主题（投影环境暗时用） |
| `?` | 快捷键帮助 |

地址栏的 `#12` 就是页号，刷新后停在原处，也可以直接分享某一页。
